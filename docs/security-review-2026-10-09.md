## Compatibility and scope

- CanonicalPath remains lexical-only. Go CanonicalFS/os.Root is the actual filesystem boundary.
- CLI callers must replace `-token` with `-token-file` or `CANONICALFS_DAEMON_TOKEN`; remote listeners need TLS. Tokens need at least 32 characters. Unix token files must be owner-only; Windows hosts must protect token-file ACLs.
- Unity bridge reads need a registered daemon client. There is no local-file fallback. Files above the byte cap fail rather than loading then truncating.
- Bounded extraction accepts ordinary single-disk ZIPs with an exact central directory, rejects ZIP64/embedded-prefix layouts, refuses overwriting existing files, and may leave earlier complete entries after an error. It removes the incomplete entry.
- Local publication disables lifecycle scripts. Build and pack artifacts before invoking the registry wrapper. Optional signing needs a verified absolute UPM_CLI_PATH.
