Migration: GDScript callers must check `result.ok` before reading `result.value`; errors expose `result.error`. Install the CMD wrapper with its sibling `packages/powershell/CanonicalPath/DaemonClient.cs`. Windows token files must have private DACLs before secrets are written. Embedded Go callers must supply CSPRNG-generated tokens of at least 32 bytes. Optional `unity:pack:signed` and `unity:npm:publish:signed` commands now fail closed; use the ordinary release workflow. This release does not claim Unity signer authentication.

Go now requires 1.25+ to use patched `golang.org/x/sys v0.44.0` for Windows ACL APIs. Windows-targeted govulncheck found the older compatible dependency's `GO-2026-5024` overflow in `NewNTUnicodeString` (not called by the daemon); selecting the fixed version removes that dependency finding as well. Linux- and Windows-targeted govulncheck and npm audit are clean.

Unity's [official CLI workflow](https://docs.unity3d.com/6000.3/Documentation/Manual/upm-cli.html) documents signed packing. The removed filename-presence check did not authenticate those signatures, so it cannot serve as a publication gate.
